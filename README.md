# CORE SMP Website

A lightweight, responsive static website for CORE SMP.

## Pages
- `index.html` — homepage, server connection section, and community information.
- `store.html` — separate store landing page; checkout is intentionally inactive.
- `styles.css` — shared responsive styling.
- `script.js` — mobile navigation, copyright year, and copy-IP interaction.

## Before publishing
1. Replace `YOUR SERVER IP` in `index.html` with the confirmed server address.
2. Add the official Discord invite in the homepage community section.
3. Confirm the final store packages and review them against Minecraft's current commercial-use guidelines.
4. Have an eligible adult account holder handle any merchant/payment account setup. This site does not collect payments or card details.

## Hosting
This is a static site. It can be deployed with a static hosting provider such as Cloudflare Pages. Connect this repository and use the repository root as the project directory; no build command is required.
