# CORE SMP Website

A static website for CORE SMP, built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — homepage, server address, and Discord community link.
- `store.html` — planned store tiers. Checkout is intentionally inactive until a compliant store provider and adult-managed payment account are ready.
- `styles.css` — responsive black-and-gold styling.
- `script.js` — mobile navigation, current year, and copy-server-address button.

## Server details
- Minecraft Java address: `cores1.smp.quest`
- Discord: https://discord.gg/znxwKpH2S9

## Deploy
This is a static site and can be deployed with a static hosting provider such as Cloudflare Pages. Connect this repository and use the root directory; no build command is required.

Before enabling purchases, have a parent/guardian manage the merchant account and review the provider's eligibility rules and Minecraft commercial-use guidelines.
